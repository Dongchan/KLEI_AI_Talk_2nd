따라 하기: 폴더와 AGENTS.md 만들기

아래 내용으로 이 폴더에 AGENTS.md를 만들고, 거기 적힌 폴더를 모두 만들어 줘. 한글 파일은 편집 도구로 UTF-8로 써 줘.

# 견본 프로젝트 작업 규칙

세션을 시작하면 `AGENTS.md`와 `Recent_Working_history.md`를 먼저 읽는다. 부족하면 `Working_history.md`를 읽는다.

- `AGENTS.md`: 이 폴더의 규칙. Codex가 세션 시작 때 읽는다.
- `Requests.md`: 요청을 정리한다.
- `Plan/`: 계획 문서를 둔다.
- `Working_history.md`: 작업 이력 전체를 맨 위가 최신이 되게 남긴다.
- `Recent_Working_history.md`: 최근 3건만 둔다.
- `Reference/`: 참고 자료 원문을 둔다.
- `data/`: 내려받은 원자료를 둔다. git에서 제외한다.
- `scripts/`: 데이터를 받고 가공하는 코드를 둔다.
- `output/`: 결과 파일(CSV 등)을 둔다.
- `docs/`: 사람에게 보여 줄 문서를 둔다.

일을 마칠 때마다 `Working_history.md` 맨 위에 시각, 사용자 지시(원문 그대로), 한 일, 판단 근거, 남은 일을 적는다. 같은 내용을 `Recent_Working_history.md` 맨 위에도 넣고 3건이 넘으면 가장 오래된 것을 지운다.

`*API*.txt`는 열어 보지 않는다. 키 값이 화면이나 대화에 나오지 않게, 파일에서 바로 환경 변수로 넣는 명령을 쓴다. 키는 환경 변수 이름으로만 쓴다. 키 값을 코드·결과 파일·작업 이력에 적지 않는다.

한글 파일은 편집 도구로 UTF-8로 쓴다. 명령줄에 한글을 직접 넣지 않는다. PowerShell로 파일을 읽을 때는 `Get-Content -Encoding UTF8`을 쓴다.

결과 파일을 만든 코드는 `scripts/`에 남긴다.

CSV는 UTF-8(BOM 포함)으로 저장한다(엑셀에서 한글이 깨지지 않게).
전문은 참고 R1 장에도 있음

AGENTS.md 견본 전문

견본 프로젝트 작업 규칙

세션을 시작하면 AGENTS.md와 Recent_Working_history.md를 먼저 읽는다. 부족하면 Working_history.md를 읽는다.

AGENTS.md: 이 폴더의 규칙. Codex가 세션 시작 때 읽는다.

Requests.md: 요청을 정리한다.

Plan/: 계획 문서를 둔다.

Working_history.md: 작업 이력 전체를 맨 위가 최신이 되게 남긴다.

Recent_Working_history.md: 최근 3건만 둔다.

Reference/: 참고 자료 원문을 둔다.

data/: 내려받은 원자료를 둔다. git에서 제외한다.

scripts/: 데이터를 받고 가공하는 코드를 둔다.

output/: 결과 파일(CSV 등)을 둔다.

docs/: 사람에게 보여 줄 문서를 둔다.

일을 마칠 때마다 Working_history.md 맨 위에 시각, 사용자 지시(원문 그대로), 한 일, 판단 근거, 남은 일을 적는다. 같은 내용을 Recent_Working_history.md 맨 위에도 넣고 3건이 넘으면 가장 오래된 것을 지운다.

*API*.txt는 열어 보지 않는다. 키 값이 화면이나 대화에 나오지 않게, 파일에서 바로 환경 변수로 넣는 명령을 쓴다. 키는 환경 변수 이름으로만 쓴다. 키 값을 코드·결과 파일·작업 이력에 적지 않는다.

한글 파일은 편집 도구로 UTF-8로 쓴다. 명령줄에 한글을 직접 넣지 않는다. PowerShell로 파일을 읽을 때는 Get-Content -Encoding UTF8을 쓴다.

결과 파일을 만든 코드는 scripts/에 남긴다.

CSV는 UTF-8(BOM 포함)으로 저장한다(엑셀에서 한글이 깨지지 않게).
